# Vokabeltrainer

Englisch-Vokabeltrainer als Android-App. Liest zweispaltige PDF-Listen (Englisch | Deutsch), fragt in drei Richtungen ab und nimmt Antworten getippt, gesprochen oder per Multiple Choice entgegen. Spracherkennung und Vorlesen laufen über Android selbst.

**Herunterladen:** https://github.com/Thomas1576000/vokabeltrainer/releases/latest/download/Vokabeltrainer.apk

Jede Änderung an `main` baut automatisch eine neue Version.
